# Contributor documentation

The user documentation (install, guides, reference) is the website in [`website/`](../website), published at
<https://rungeass.com/docs/>. These pages are for people working on Geass itself.

| Page | What it covers |
| --- | --- |
| [development.md](development.md) | Tools, the repository layout, building, running Geass from your machine, and every kind of test. |
| [releasing.md](releasing.md) | How versions are numbered, what a release contains, how to cut one, and the one-time repository setup. |
| [design.md](design.md) | The visual and interaction system ("The Contract") for the dashboard, website and installer output. |
| [demo-app.md](demo-app.md) | A public image to deploy by hand when trying a change. |

See also [CONTRIBUTING.md](../CONTRIBUTING.md), [SECURITY.md](../SECURITY.md) and [CHANGELOG.md](../CHANGELOG.md).
