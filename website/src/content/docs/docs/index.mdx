Geass turns servers you already own, from a single VPS to a rack of bare metal, into a managed cloud. You ship apps
and databases from one dashboard, a command line or an AI agent, scale across machines, back up your data, and
connect the clouds you already use, while everything runs on hardware you control.

These docs describe what Geass does today: what each feature is for, how to use it, what it does under the hood,
and what to check when something goes wrong.
