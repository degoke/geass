Geass changes servers that you already own into a managed cloud. These servers can be one VPS or a rack of bare
metal. With Geass, you can do these tasks:

- Ship apps and databases from one dashboard, a command line, or an AI agent.
- Scale across machines.
- Back up your data.
- Connect the clouds that you already use.

All of these workloads run on hardware that you control.

These docs describe what Geass does today:

- What each feature is for.
- How to use each feature.
- What each feature does under the hood.
- What to check when something goes wrong.
