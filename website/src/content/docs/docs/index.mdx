Geass gives your own servers the workflow of a managed cloud. You install Geass with one command. Then you do the rest
in the dashboard:

1. Create a project.
2. Add services, databases, and buckets.
3. Click **Deploy changes**.

Geass runs them, connects them, backs them up, and shows you their logs and metrics. You do not need to know how Geass
works inside to use it.

## Under the hood

Geass runs on [K3s](https://k3s.io/), a small Kubernetes distribution. You do not need to know Kubernetes to use
Geass. If you want to know how Geass works, or you must repair a server, see [How Geass works](/docs/overview/how-it-works/)
and [Troubleshooting](/docs/operations/troubleshooting/).
