# Geass Brand Kit

The Geass identity is built around a geometric **open cluster boundary** that also forms a `G`. The central connected node represents the Geass control plane coordinating infrastructure within that boundary.

## Included assets

### Logos

- `logos/geass-symbol.svg` — primary two-colour symbol
- `logos/geass-horizontal-dark.svg` — horizontal lockup for dark backgrounds
- `logos/geass-horizontal-light.svg` — horizontal lockup for light backgrounds
- `logos/geass-stacked-dark.svg` — stacked lockup with tagline
- `logos/geass-symbol-mono-white.svg` — one-colour white symbol
- `logos/geass-symbol-mono-black.svg` — one-colour black symbol

## Typography

- Interface and brand: **Inter Variable**
- Technical content: **Geist Mono**, with IBM Plex Mono as fallback

SVG wordmarks use live text so they remain editable. For final trademark or print production, convert the `Geass` wordmark to outlines using the approved Inter font file.

## Usage

- Use the horizontal lockup as the default website and documentation logo.
- Use the symbol for favicons, repository avatars, app icons, and compact navigation.
- Use monochrome artwork when reproduction allows only one colour.
- Maintain clear space equal to one quarter of the symbol height.
- Do not rotate, stretch, outline, glow, bevel, recolour, or place the logo over visually noisy imagery.
- Do not use the detailed internal node connections below 24px; use `favicon.svg` instead.
